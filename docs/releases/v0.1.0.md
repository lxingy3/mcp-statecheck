# mcp-statecheck v0.1.0

`mcp-statecheck` is a stateful differential testing tool for Model Context
Protocol implementations. This first release focuses on reproducible local
evidence: canonical actions, normalized wire observations, minimized failure
artifacts, deterministic replay, and offline reports.

## Included

- Real stdio and Streamable HTTP execution with hard timeouts and cleanup.
- Five seeded Hypothesis `RuleBasedStateMachine` fixtures covering HTTP error
  classification, duplicate concurrent request IDs, second SSE resumption,
  requests before initialization completes, and cancellation correlation.
- Stable failure signatures, shrinking, saved-artifact reload, and ten fresh
  replay attempts per fixture.
- An installed CLI with `check`, `replay`, `matrix`, and `report`.
- JSON, JUnit XML, SARIF 2.1.0, and script-free single-file HTML reports.
- A composite GitHub Action, Ubuntu and Windows CI, scheduled macOS acceptance,
  and full-history secret scanning.

## Benchmark snapshot

The checked-in matrix contains 16 real client cells:

| Language | v1 client | v2 client |
| --- | --- | --- |
| Python | `mcp 1.28.1` | `mcp 2.0.0` |
| TypeScript | `@modelcontextprotocol/sdk 1.30.0` | `@modelcontextprotocol/client 2.0.0` |

Each client runs against MCP `2025-06-18` and `2025-11-25` over stdio and
Streamable HTTP. All 16 generated traces match their checked-in deterministic
goldens. The HTTP cells additionally verify post-initialize session and
protocol headers, content negotiation, session deletion, and listener cleanup.

## Acceptance evidence

- All five controlled failures shrink to their expected actions and reproduce
  the same signature in 10/10 fresh attempts.
- Clean wheel and sdist installations import only from their isolated
  environments.
- The wheel-installed CLI replays all five versioned, allowlisted target
  recipes from an untrusted working directory without importing from it.
- Installed stdio and HTTP checks produce valid JSON, JUnit, SARIF, and HTML
  artifacts and confirm process, client, session, and listener cleanup.
- The wheel-installed 16-cell matrix matches the repository goldens without
  modifying package resources.

## Limitations

- The `check` command is a bounded smoke profile, not a full conformance suite.
- The `deep` profile is deferred.
- Automatic replay is limited to the five package-controlled target recipes.
  Artifacts cannot select arbitrary commands, URLs, environments, or working
  directories.
- The matrix uses one controlled valid client sequence and does not represent
  every SDK API or real-world server.
- The protocol matrix covers `2025-06-18` and `2025-11-25`. The newly released
  stateless `2026-07-28` revision needs a separate action profile and is not
  supported by v0.1.
- Injected fixture failures demonstrate detector behavior; they are not claims
  of defects in the upstream SDKs.
- Only Python 3.12 is supported by v0.1.
- MCP Tasks, A2A, accounts, databases, cloud services, and collaboration
  features are outside this release.

## Install

```console
uv tool install mcp-statecheck==0.1.0

```
